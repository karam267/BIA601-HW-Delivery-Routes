# مشروع تخطيط جولة توصيل

**BIA601 — الخوارزميات الذكية — الوظيفة الثالثة (F25) — مجموعة BIA601-HWخوارزميات ذكية**

المستودع: https://github.com/karam267/BIA601-HW-Delivery-Routes

يقارن المشروع ثلاث خوارزميات مكتوبة محليا: الخوارزمية الجينية GA، وسرب جسيمات بتباديل المواقع PSO، ومستعمرة النمل ACO. المطلوب جولة تبدأ من المستودع 0، تزور بقية المواقع مرة واحدة، ثم تعود إلى المستودع بأقل مسافة. الأعداد 10 و20 و40 تشمل المستودع.

## التشغيل

يحتاج المشروع إلى Python 3.12 أو أحدث. ثبتت التجربة المرفقة على Python 3.12.14 مع إصدارات المكتبات المحددة في requirements.txt. من مجلد project:

```text
python -m pip install -r requirements.txt
python experiment.py
python check_results.py
```

ينشئ الأمر الثاني نتائج التجربة الكاملة داخل results. المسارات محسوبة من موقع البرنامج، لذلك لا يعتمد التشغيل على اسم المجلد الأب أو لغة مساره. تبقى النتائج الأصلية محفوظة عند استخدام مجلد آخر للتجربة السريعة:

```text
python experiment.py --repeat 2 --output ../trial_results
python check_results.py --results ../trial_results
```

ولإعادة حساب المراجع الدقيقة وإعادة أول تشغيل لكل خوارزمية وحالة، ومقارنة المسارات وسجل التقارب كاملا:

```text
python check_results.py --rerun
```

## تصميم التجربة

- تسع خرائط اصطناعية: ثلاثة أحجام، ولكل حجم توزيع منتظم وآخر متجمع وثالث حلقي. الإحداثيات المسجلة في nodes.csv هي بيانات التجربة الفعلية. الوحدة متر، والمسافة هي المسافة المستقيمة مقربة إلى أقرب عدد صحيح؛ لا تمثل شبكة طرق فعلية.
- 20 تشغيلا مستقلا لكل خوارزمية ولكل خريطة، أي 540 تشغيلا. البذور محفوظة في trials.csv. إعدادات البحث ثابتة قبل التجارب في protocol.json.
- 32 مرشحا و160 دورة بعد التهيئة، أي 5152 تقييما لمسافة جولة لكل تشغيل. إعادة تقييم النخبة في GA محسوبة ضمن العدد. الخوارزميات الثلاث تبدأ بمرشح من طريقة الجار الأقرب NN وتحتفظ بأفضل حل. لذا لا تعود بنتيجة أسوأ من NN، لكن تساويها معها لا يعني تحسنا.
- في ACO تمثل الدورة 0 المستعمرة الأولى، ويدخل NN ضمنها. توجد 161 مستعمرة؛ تحديث الفيرومون الأخير لا يضيف تقييمات.
- تحسب قيمة مثلى لكل خريطة بحل صحيح ثنائي للحواف مع قيود الدرجة 2، ثم إضافة قيود منع الدورات الجزئية حتى الحصول على جولة واحدة وإثبات الحد السفلي. تستدعي هذه المقارنة المرجعية فقط scipy.optimize.milp؛ أما GA وPSO وACO فمنفذة في search.py. عند غياب شهادة الأمثلية يتوقف البرنامج بخطأ بدلا من اعتبار الحل غير المثبت مثاليا.
- الفجوة = 100 × (مسافة الجولة − المسافة المثلى) / المسافة المثلى. يحسب النجاح التقريبي عند بلوغ فجوة لا تتجاوز 1%، ويسجل أول موضع في المنحنى يبدأ من 0. الحقل فارغ عند عدم الوصول، ومتوسطه يشمل حالات الوصول فقط.
- الانحراف المعياري في aggregate.csv هو متوسط الانحرافات العينية داخل الخرائط الثلاث، باستخدام ddof=1، ولا يخلط اختلاف الخريطة بعشوائية الخوارزمية. أما الرسم الصندوقي فيجمع 60 نتيجة لكل حجم ويشمل الاختلافين.
- الزمن هو زمن البحث فقط، شاملا التهيئة وNN، دون الرسم أو المرجع الدقيق. الذاكرة هي ذروة التخصيص التي تتبعها tracemalloc في تشغيل إضافي بالبذرة الأولى لكل خريطة، ثم متوسط الخرائط؛ لا تمثل ذاكرة العملية الكاملة RSS. قياس الذاكرة خارج قياس الزمن. تتغير الأزمنة قليلا باختلاف الجهاز والحمل.
